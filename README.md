# 基于 FPGA 的智能脑控轮椅系统

本项目面向手部操作受限的轮椅使用者，探索通过注视屏幕上的闪烁目标发出控制指令。系统由脑电采集帽、ACG720 FPGA 开发板、HDMI 显示屏和电动轮椅控制接口组成。FPGA 接收脑电数据，在板端完成目标识别和指令确认，同时提供注意力评分与情绪推理。

**关键词**：脑机接口（BCI）、稳态视觉诱发电位（SSVEP）、滤波器组典型相关分析（FBCCA）、FPGA、脑控轮椅

## 系统如何工作

1. **视觉刺激**。HDMI 界面显示 7、9、11、15 和 17 Hz 五种闪烁目标。方向控制、功能控制、速度与求助三个页面复用这五种频率。
2. **脑电识别**。采集端通过串口传输脑电数据。SSVEP 通路使用 FBCCA，将滤波后的脑电与各候选频率的参考信号进行比较。
3. **指令输出**。识别结果经过连续窗口确认后，按当前页面映射为轮椅指令，例如前进、后退、左转或右转。HDMI 界面显示交互状态。

## FPGA 实现

| 模块 | 实现方式 |
| --- | --- |
| SSVEP 识别 | 使用专用定点硬件完成滤波、协方差计算和矩阵求解。滤波状态驻留在局部寄存器中，参考信号利用周期性折叠减少重复的协方差乘加。 |
| 注意力评分 | 使用四通道并行 DFT 提取脑电频带能量，供注意力评分逻辑使用。 |
| 情绪推理 | 采用共享乘加数据通路的紧凑定点网络，使用训练好的定点权重执行硬件推理。 |
| 显示与控制 | FPGA 生成 HDMI 画面和视觉刺激，根据当前页面分发确认后的控制指令。 |

## 工程构建

目标器件为 Gowin GW5AT-LV60PG484AC1/I0（GW5AT-60B），顶层模块为 `fusion_top`。使用 Gowin Designer V1.9.12.03 打开 [fusion.gprj](fusion.gprj)，工程配置使用 SystemVerilog 2017，头文件搜索路径为 `src`。也可以在工程根目录执行以下命令进行综合和布局布线。

```sh
gw_sh build.tcl
```

| 目录 | 内容 |
| --- | --- |
| [src](src/) | RTL 源码与头文件 |
| [constraints](constraints/) | 板级引脚与时钟约束 |
| [assets](assets/) | 片上存储初始化数据 |
| [tools](tools/) | 硬件与初始化数据生成脚本 |
